The default marketplace database of official plugins for Pipe Bomb.

## Usage

To get quick access to the official plugin list, add the following URL to your Pipe Bomb server as a Marketplace:

```
https://raw.githubusercontent.com/Pipe-Bomb/marketplace/refs/heads/master/marketplace.json
```

## Credits & Contributing

Credit goes to the Pipe Bomb team and the maintainers of the individual plugins. This repo isn't accepting contributions. If you have a plugin you'd like to add, check out the Community Marketplace.
